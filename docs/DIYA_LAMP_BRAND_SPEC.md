## Position

**Stop starting over with every AI.** A proposed user-owned home for chosen
context, compatible agents, task-scoped permissions and unfinished work.
First persona: an individual who uses several AI tools and repeatedly rebuilds
preferences, project context and task state. Long-term ambition is a personal
agent runtime, not another essay tool or news feed.

## Delivered by the website versus proposed

Delivered: three scripted fictional views (Context/Permissions/Checkpoints),
selected/proposed scope inspection and temporary keep/remove sample checkpoints.
No accounts or private files connected, no provider calls and no execution.
Early access opens a draft to the existing public diyalamp@proton.me inbox;
it sends nothing automatically and asks not to include private files/secrets.

Proposed: open-source local-first context vault and permissioned runtime; an
optional paid managed service with CockroachDB-backed durable cross-device sync.
Provider compatibility, encryption, permission enforcement, data deletion and
real recovery remain unimplemented/unverified. Paid hosted use before service
access; no checkout or activated price on this page. The earlier writing engine
is preserved separately and does not implement this new runtime.
