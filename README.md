# 🪔 diyalamp website

A writing and decision-review tool for product managers. Positioning follows the Defensive Writing Product strategy: individual craft, rigorous reasoning, and an organizational culture of defensible decisions.

GitHub Pages publishes `dist`. The page distinguishes planned Personal, Teams, and Enterprise offerings from the currently available scripted pricing-memo demo. No hosted AI, checkout, account creation, or claim of validated outcomes is present.

The demo supports examining a causal claim, accepting/undoing a revision, reconsidering its dependent recommendation, previewing/applying/undoing narrative order, and viewing a decision brief. All example data is fictional and browser-local. The pilot link opens an email draft; it does not send anything automatically.

Serve `dist` with a static HTTP server for preview. Keep credentials and customer documents out of this public repository.
