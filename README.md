# 🪔 diyalamp website

AI-assisted essay writing: find your flow and write a better essay.

The site presents a writing tool with focused feedback on clarity, structure, reasoning, and voice. It is not a course or a required curriculum. The implementation form factor remains undecided.

## Preview

Serve `dist` with any static web server. The writing desk demonstrates fictional draft review and revision. The final self-check is local and does not invoke live AI or transmit text. Pricing names are Novice, Scribe, and Sage; paid prices are proposed and checkout is unavailable.

The public writing engine remains separate from private hosted accounts, billing, and operations. GitHub Pages publishes `dist`. Do not add credentials or customer drafts to this repository.
