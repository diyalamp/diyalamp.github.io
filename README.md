# 🪔 Diya Lamp

Made by JRXNA. Local static prototype of an open-source Notion AI writing plugin for product managers drafting decision memos.

Run `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist` and open http://127.0.0.1:4173/.

Three sections: interactive decision review, writing philosophy, replayable workflow. The demo is deterministic; it does not evaluate evidence, call an AI service, or access Notion. Inputs stay in memory. Planned integration, public repository, and license remain undefined. Inter uses Google Fonts; branding uses literal Apple-rendered emoji on macOS, and the favicon is a local Apple Color Emoji rendering. Lucide SVGs are local and attributed in THIRD_PARTY_NOTICES.md. Served CSS/JS are compact without build dependencies.
